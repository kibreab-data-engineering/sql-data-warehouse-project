Objective

To design and build end-to-end data engineering solutions by extracting data from CSV files, transforming it through Bronze, Silver, and Gold layers, and loading structured datasets into SQL Server for analytics and reporting.

Project Workflow
Source
CSV Files
ETL Process
Extract data from CSV files
Load raw data into Bronze schema
Clean and transform data into Silver schema
Create business-ready aggregated tables in Gold schema
Load final transformed data into SQL Server
SQL Server Schemas
Bronze → Raw ingestion layer
Silver → Cleaned and transformed data
Gold → Business and reporting tables
